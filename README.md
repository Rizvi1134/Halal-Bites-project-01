# Halal Bites 🍔

## 📌 Description
A food ordering web application built with PHP and MySQL.

## 🚀 Features
- Admin dashboard
- Order system
- Invoice generation
- Admin login system
- Index system
- logout system

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## ⚙️ Setup
1. Install XAMPP
2. Import halal_bites.sql into phpMyAdmin
3. Run on localhost
